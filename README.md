# ONG Esperança

Site institucional desenvolvido para a ONG Esperança, com o objetivo de apresentar seus projetos sociais e facilitar o acesso às informações e ao cadastro de interessados.

O projeto foi desenvolvido como prática de **desenvolvimento Front-End**, utilizando HTML, CSS e JavaScript.

## ✨ Funcionalidades

* Página inicial com apresentação da instituição.
* Página dedicada aos projetos sociais.
* Formulário para cadastro de interessados.
* Máscaras de entrada para CPF, telefone e CEP.
* Validação dos campos do formulário.
* Mensagem de confirmação após o envio.
* Layout adaptável a diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

* **HTML5** — estruturação e organização semântica das páginas.
* **CSS3** — estilização e responsividade.
* **JavaScript** — manipulação do DOM, formatação de campos e validação do formulário.
* **Git e GitHub** — versionamento e armazenamento do código-fonte.

## 📂 Estrutura do projeto

O projeto está organizado em arquivos HTML para as páginas, uma folha de estilos CSS e um arquivo JavaScript para as funcionalidades do formulário.

## 🎯 Objetivo do projeto

Aplicar conhecimentos de desenvolvimento Front-End na construção de um site institucional, praticando estruturação de páginas, estilização, organização de arquivos, responsividade e validação de formulários com JavaScript.
